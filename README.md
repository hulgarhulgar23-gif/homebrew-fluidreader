# Fluid Reader Homebrew Tap

Homebrew cask for [Fluid Reader](https://github.com/hulgarhulgar23-gif/fluid-reader),
a local-first macOS menu-bar app that reads and acts on screen content.

## Install

```sh
brew install --cask hulgarhulgar23-gif/fluidreader/fluid-reader
```

Releases are not notarized by Apple yet: on first launch, right-click
`FluidReader.app`, choose **Open**, then click **Open** again.

## Upgrade

```sh
brew upgrade --cask fluid-reader
```
